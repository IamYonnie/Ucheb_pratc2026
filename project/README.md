# Лабораторная работа с использованием AR (КТ2)
Консольное приложение, автоматизирующее операции бизнес-процесса
«Подготовка и проведение лабораторной работы с использованием AR-визуализации».

## Язык и версия
- Язык: C# 9.0
- Платформа: .NET 8.0
- Архитектура: процедурная реализация

## Сборка и запуск
1. Скачать проект (папка project)
2. Открыть терминал в папке
3. Выполнить сборку командой *dotnet build*
4. Запустить пограмму командой *dotnet run*

## Реализованные операции
1. Проверить наличие оборудования и реактивов в функции CheckARAssets()
2. Заменить оборудование (сброс AR-сцены) в функции ResetARScene()
3. Подготовить методические указания в функции GenerateMethodology()
4. Провести инструктаж по ТБ в функции ConductSafetyBriefing()

## Описание работы программы
При запуске программы в консоли выводится меню выбора действий, соответствующих реализованным операциям. При вводе соответствующей цифры, программа запускает функцию. Если введённое число не принадлежит диапазону 1-4, в консоли появляется уведомление об ошибке ввода. 
Принцип работы каждой функции:
1. Программа смотрит каждый нужный файл и проверяет, есть ли он в списке доступных. Если какого-то файла нет, то пишет об этом с указанием файла.
2. Программа берёт каждый объект со сцены, находит его в списке исходных координат и возвращает на место.
3. Выводит в консоль автора, название работы и текст методических указаний
4. Выводит в консоль правила техники безопасности
