# Лабораторная работа с использованием AR (КТ3)
Объектно-ориентированная версия программы из КТ2. Консольное приложение, автоматизирующее операции бизнес-процесса «Подготовка и проведение лабораторной работы с использованием AR-визуализации».

## Язык и версия
- Язык: Java 21
- Платформа: JDK 21 (LTS), совместим с JDK 17+
- Архитектура: объектно-ориентированная реализация (ООП)

## Сборка и запуск
1. Скачать проект (папка src/java)
2. Открыть папку src/java в VS Code
3. Установить расширение Extension Pack for Java
4. Открыть файл app/Main.java
5. Нажать Run

Для запуска из командной строки:
bash
cd src/java
javac -encoding UTF-8 -d build @sources.txt
java -Dfile.encoding=UTF-8 -cp build Main

## Реализованные операции
1. Проверить наличие оборудования и реактивов в методе ArScene.checkAssets()
2. Заменить оборудование (сброс AR-сцены) в методе ArScene.resetScene()
3. Подготовить методические указания в методе MethodologyService.generate()
4. Провести инструктаж по ТБ в методе SafetyBriefingService.conduct()

## Описание работы программы
При запуске программы в консоли выводится меню выбора действий, соответствующих реализованным операциям. При вводе соответствующей цифры программа запускает метод. Если введённое число не принадлежит диапазону 1-5, в консоли появляется уведомление об ошибке ввода.

Принцип работы каждой операции:
1. Программа проверяет каждый нужный файл по списку доступных. Если какого-то файла нет, то пишет об этом с указанием файла.
2. Программа берёт каждый объект со сцены, находит его в списке исходных координат и возвращает на место.
3. Выводит в консоль название работы, описание и список оборудования.
4. Выводит в консоль правила техники безопасности.
5. Остановливает программу

## Структура классов
- model/ - предметная область: `Person`, `Student`, `Teacher`, `LabWork`, `Equipment`, `EquipmentSet`, `Report`
- rules/ - правила проверки: интерфейс `AssetCheckRule` и реализации `ByFileNameRule`, `ByResourceTypeRule`
- scene/ - AR-сцена: `ArScene`, `SceneAsset`, `SceneObject`, `MethodologyService`, `SafetyBriefingService`
- app/Main - точка входа с demo-данными из КТ2
